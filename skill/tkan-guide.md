# Ткань (Сайтик): устройство и форма работы

Короткая инструкция агенту, который ставит плагин `saitik-interface`. Прочитай — и ты знаешь,
как у нас всё устроено и как работать, не придумывая своё.

## Что такое Ткань

Ткань — сеть узлов-страниц (`https://<домен>/<id>`, домен зависит от контура). Узел — не «сайт»,
а страница-сообщение: человек читает её целиком. У каждого узла есть владелец, палитра (тема),
блоки (Markdown, кнопки, картинки, врезки-симбиозы) и порядок блоков.

- **Два контура:** `saitik.su` (прод) и `syndicate.su` (полигон). Отличаются только `.env` ядра.
- **Симбиоз** — врезка чужого узла на свою страницу: один источник, меняется везде.
- **Язык узла (SaitikLang)** — текстовый формат правки: действия `Созидание` (новый блок),
  `Огранка` (править текст/стиль), `Трансмутация` (заменить элемент), `Разрушение` (удалить),
  `Сдвиг`, `Скопировать`, `Тема`. Строка `---` внутри текста рвёт блок — разделитель в текстах
  писать длинным тире `───`.
- **Доступ:** MCP-токен агента (выдаёт владелец). Чужие узлы — только чтение.

## Инструменты, которые даёт плагин

- **`screen`** — экран узла: сцена задачи, ответ, шаги, знаки-лента, арт, снимок, витрина, уборка.
  `ops` — несколько действий одним вызовом. Узел — параметр или профиль агента.
- **`node`** — Ткань напрямую: чтение узла, запись скриптом SaitikLang, список узлов, создание,
  симбиозы (list/add/switch/remove), загрузка файла, `call` — любой инструмент Ткани.

## Форма работы (как принято)

1. **Ответ человеку — правкой страницы**, не текстом в чат: человек читает СТРАНИЦУ.
2. **Начал задачу — собери сцену** (`scene`): что делаю и шаги. Человек видит ход дела.
3. **Шаг закрыл — отметь сразу** (`step N ok`), не в конце.
4. **Ход — в журнал** (`report ... --note`): что сделал — остаётся в Ткани.
5. **Знаки:** цвет блока — роль (⚪ обычный, 🔆 акцент, 🟢 готово, 🟡 внимание, 🔴 опасно, 🔵 кнопка);
   смысл — иконка. Не изобретать свои схемы.
6. **Одна мысль — один блок**; группа 3–5 блоков; внутри блока 2–3 строки.
7. **Секреты — в хранилище**, в узлах и чате их нет: узел читается по адресу любым.

## Профиль агента (обязательно при установке)

Личные узлы — не в коде. При установке запиши в `~/.hermes/config.yaml`:

```yaml
plugins:
  entries:
    saitik-interface:
      node: <узел-интерфейс агента>
      home: <узел-дом>
      journal: <узел-журнал>
```

или переменные окружения `SAITIK_NODE` / `SAITIK_HOME` / `SAITIK_JOURNAL`.
Без профиля `screen` не угадывает узел — требует `node` явным доводом (защита от записи на чужую
страницу). Чужой узел можно указать всегда, но писать в него может только владелец.

## Первая задача агенту (типовая)

```
screen {op: scene, task: "Знакомство", steps: ["осмотрелся", "собрал экран"]}
screen {op: say, text: "Я на месте."}
node {op: read, id: <свой узел>}
```

Ответ человеку — правкой его страницы, в чат — одна короткая строка.
