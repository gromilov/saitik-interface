# saitik-interface

**Страница вместо чата.** Плагин [Hermes Agent](https://github.com/NousResearch/hermes-agent):
даёт агенту экран на узле Ткани и прямой доступ к Тканю — изнутри шлюза, без запуска процессов.

Человек читает **страницу узла**, а не поток чата. Агент собирает сцену задачи, отвечает правкой
страницы, отмечает шаги и пишет ход в журнал. Форма работы — в комплекте, придумывать не надо.

## Что даёт

**Инструмент `screen`** — экран узла:
- сцена задачи одним вызовом (`scene`: заголовок + шаги + статус);
- живой ответ (`say`), шаги (`step` / `step all ok`), знаки-лента (`strip`);
- арт, снимок, панель, вопросы, витрина (`pin`), уборка (`clear`, `del`);
- поле `ops` — несколько действий **одним вызовом** (сцена + шаги + ответ);
- узел — параметр или профиль агента; без узла отказывается писать (защита от промаха).

**Инструмент `node`** — Ткань напрямую:
- чтение узла, запись скриптом языка узла (SaitikLang);
- список узлов, создание, врезки-симбиозы (list / add / switch / remove);
- загрузка файлов, `call` — любой инструмент Ткани по имени.

**Навык в комплекте** (`skill/tkan-guide.md`): что такое Ткань, язык узла и его ловушки,
форма работы, профиль агента, типовая первая задача.

## Установка

```bash
hermes plugins install gromilov/saitik-interface
hermes plugins enable saitik-interface
```

## Профиль агента (обязательно)

Личные узлы — не в коде. После установки впиши в `~/.hermes/config.yaml`:

```yaml
plugins:
  entries:
    saitik-interface:
      node: <узел-интерфейс агента>   # куда агент пишет экран
      home: <узел-дом>                # память агента
      journal: <узел-журнал>          # ходы
```

или переменные окружения `SAITIK_NODE` / `SAITIK_HOME` / `SAITIK_JOURNAL`.

Без профиля `screen` не угадывает узел — требует `node` явным доводом. Это защита: агент никогда
не пишет «куда-то» — только в свой узел или в явно указанный (права проверяет Ткань).

## Что нужно от владельца

- MCP-токен агента (выдаётся в Ткани);
- узел-интерфейс (страница агента), при желании — узел-дом и журнал;
- доступ к MCP ядра Ткани (плагин ходит тем же путём, что и MCP-клиент).

## Как это работает внутри

Плагин — тонкий слой поверх проверенной механики: экран собирается тем же кодом, что и
cron-скрипты владельца (один источник правды), а Ткань доступна тем же HTTP-путём, что и MCP.
Состояние экрана — в памяти плагина по узлам; долговечное живёт в самих узлах: перезапуск шлюза
ничего не ломает. Регистр действий — данные (`registry.py`): добавить действие = одна строка.

## Совместимость

- Hermes Agent (Linux/macOS/Windows), Python 3.11+
- Ткань: ядро с MCP-эндпоинтом (два контура: прод и полигон — отличается только домен)
- `pyyaml` (есть в окружении Hermes)
